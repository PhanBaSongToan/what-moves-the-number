# experiments

Everything that produces a number in `../paper/paper.tex` lives here.

## What is in this folder

| File | Role |
|---|---|
| `run_experiment.py` | Trains one model. The only place a model is defined; every reported run goes through it. |
| `run_matrix.py` | Runs the 13 configurations of the paper sequentially on one GPU. |
| `analyze_results.py` | Turns `results/` into `../paper/numbers.tex`, `tables/*.tex`, `figures/*.pdf` and `summary.json`. |
| `experiment_stats.py` | Aggregation and error-decomposition helpers. |
| `test_statistics.py` | Self-checks for the bootstrap, McNemar and error-decomposition code. |
| `build_product_disjoint_split.py` | Builds the product-disjoint split with `GroupShuffleSplit`. |
| `release_split_index.py` | Writes and verifies `data/product_disjoint_ids.csv`, the released split assignment. |
| `audit_product_split.py` | Product-group leakage audit for the official split. |
| `duplicate_audit.py` | Verbatim-duplicate audit (official vs product-disjoint split). |
| `collect_dataset_stats.py` | Dataset statistics and per-class examples quoted in the paper. |
| `extra_stats.py` | Description length statistics that explain the metadata ablation. |
| `list_examples.py` | Candidate examples per label, used to pick the ones in Table I. |
| `error_analysis.py` | Extracts the representative errors discussed in Section VI. |
| `lexical_baseline.py` | TF-IDF + linear SVM reference point on the official split. |
| `results/` | One folder per run: config, training log, best checkpoint, metrics, per-row predictions. |
| `data/product_disjoint_ids.csv` | Row-level product-disjoint assignment (compact, verifiable). |
| `legacy/` | Superseded exploratory scripts. See `legacy/README.md`. |

## Locked protocol

Every reported number comes from this protocol; nothing else changes between models.

| Item | Value |
|---|---|
| Encoder | `vinai/phobert-base-v2` |
| Max sequence length | 100 |
| Padding | dynamic per batch, multiple of 8 |
| Batch size | 32 |
| Epochs / patience | 10 / 3, early stopping on dev macro-F1 |
| Optimizer | AdamW, weight decay 0.01 |
| Encoder / head LR | 1e-5 / 5e-5 |
| Precision | bfloat16 autocast |
| Seeds | 42, 43, 44 |

## Reproduce

```powershell
# 1. install
pip install -r requirements.txt

# 2. point at the data (defaults are the paths used for the paper)
$env:VISPAM_ZIP = "C:\path\to\vispamdetectionv2_official.zip"
$env:VISPAM_DISJOINT_DIR = "C:\path\to\product_disjoint_split_seed42"

# 3. train the 13 runs (~100 min on an 8 GB laptop GPU; finished runs are skipped)
python run_matrix.py

# 4. regenerate every table, figure and inline number of the paper
python analyze_results.py
```

`run_matrix.py --only t2_single_s42` runs a single configuration;
`--smoke` does a 256-row, one-epoch sanity pass.

## Outputs per run

`results/<name>/` contains `final_test_metrics.json` (accuracy, macro-F1,
per-class scores, confusion matrix, binary-head scores, epoch history),
`training_log.csv`, `test_predictions.csv` (one row per test review with the
four class probabilities) and `best_model_state.pt`. The checkpoints are large
(about 540 MB each) and are regenerated by the script; they are not needed to
rebuild the tables.

## Data

The public release `sonlam1102/vispamdetection2` (14,306 / 1,590 / 3,974 rows) is
used as released. The product-disjoint split is built from it with
`build_product_disjoint_split.py` (seeds 42 and 43) and contains
13,985 / 1,947 / 3,938 rows.
