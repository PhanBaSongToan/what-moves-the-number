# legacy exploratory scripts

These scripts produced the exploratory numbers that appear in the first draft
of the paper (rule-augmented multi-task, weighted type loss, category-only and
description-only input, separate and gated fusion, attentive pooling, ensemble,
logit adjustment, threshold tuning, hierarchical decoding).

They are kept for provenance and **must not** be used to reproduce the numbers in
the current paper. They predate the locked protocol and differ from it in at
least one of: max sequence length (128 instead of 100), a single learning rate
of 2e-5 instead of separate encoder/head rates, fixed `max_length` padding
instead of dynamic padding, fp32 instead of bf16, and — for
`train_multitask.py` — a hard-coded inverse-frequency type loss. That means
their scores are not comparable with each other either, which is exactly the
problem the locked protocol was introduced to fix.

Every number reported in the paper is generated by `../run_experiment.py` under
one protocol; the two interventions that were re-run are the class-weighted type
loss and the metadata-concatenation input.

Two known defects, kept here rather than silently fixed because they document
why the scripts were retired:

* `train_multitask.py` hard-codes its output directory and a weighted type loss,
  so it cannot reproduce the unweighted multi-task run it is named after.
* `run_controlled_experiment.py` contains dead code at the end of `main()`
  (`classification_report(...) if False else ...`).
