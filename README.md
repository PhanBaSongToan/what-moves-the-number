# TMG301 — Text Mining

Course project for TMG301 (Text Mining). The main deliverable is an IEEE-format
paper on Vietnamese spam-review classification; the repository also keeps the
other course assignments.

## Layout

| Path | Contents |
|---|---|
| `paper/` | **The paper.** `paper.tex` (XeLaTeX + IEEEtran), generated tables, figures, `numbers.tex`, build script. |
| `experiments/` | All code that produces the paper's numbers. See `experiments/README.md`. |
| `review_20261103/` | Audit of the previous draft (findings, severity, evidence) and the verification scripts. |
| `archive/` | Superseded drafts, including the 2026-11-02 LNCS draft. |
| `assignments/` | Other course deliverables (SST-2, integrated NLP, OpenSearch deck, exam notes) still live at the repository root, unchanged. |

## Build the paper

Requires MiKTeX (or TeX Live) with `ieeetran` and XeLaTeX. Vietnamese review
text quoted in the paper needs a Unicode engine, so the build is XeLaTeX, not
pdfLaTeX.

```powershell
cd paper
xelatex paper.tex
xelatex paper.tex      # second pass resolves references and citations
```

or run `paper/build.ps1`, which does both passes and reports the page count.

The output is `paper/paper.pdf`.

## Reproduce the experiments

```powershell
cd experiments
pip install -r requirements.txt
python run_matrix.py        # 13 runs, ~100 min on an 8 GB GPU
python analyze_results.py   # regenerates tables, figures and numbers.tex
```

## What changed on 2026-11-03

The first draft was audited and found not submittable: the baseline and the
multi-task model had been trained with different protocols, two headline numbers
had no stored metrics, the PDF was a stale IEEEtran build of a one-author version
while the source was an LNCS draft with three authors, and the draft cited the
wrong first author for the reference paper. The current version addresses all of
that:

* one locked protocol for every model (`experiments/run_experiment.py`);
* three seeds for the headline comparison, paired bootstrap and McNemar test;
* both models evaluated on the product-disjoint split, not just the proposal;
* ablations re-run under the same protocol instead of a mixed-protocol table;
* a verbatim-duplicate audit on top of the product-group audit;
* label definitions with real examples, dataset statistics, error decomposition,
  per-class tables and confusion matrices;
* IEEEtran source that actually compiles, with the three authors and correct
  citation of the reference paper.

The full audit is in `review_20261103/BAO_CAO_KIEM_TRA_BAI_BAO.md` (Vietnamese).

## Notes

* Model checkpoints (~540 MB each) are regenerated by `run_matrix.py` and are not
  committed; the metrics and per-row predictions in `experiments/results/` are.
* `experiments/legacy/` holds the pre-lock exploratory scripts. Their numbers are
  not comparable with the paper and must not be mixed into it.
